cert-publisher {{ .Chart.AppVersion }} is installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

The controller runs as a Deployment ({{ .Values.replicaCount }} replica(s)). It
watches CertPublications and the cert-manager resources it owns, so a new
publication and a freshly issued certificate are acted on within seconds, and
re-checks every publication every {{ div (int .Values.controller.resyncInterval) 60 }} minutes to catch drift on the
target hosts. It requires cert-manager to already be installed in the cluster.

Create a CertPublication to start publishing certificates. See the examples at
https://github.com/charlespick/cert-publisher/tree/main/examples

Watch progress with:
  kubectl get certpublications -A
  kubectl describe certpublication <name>

A publication that cannot reach its host reports the reason on itself and is
retried with backoff; it no longer fails the controller or holds up any other
publication.
